A matrix is a verb. It does something to every point in the space simultaneously — and the grid shows what. Diagonal entries scale along the axes. Off-diagonal entries shear. The determinant measures the factor by which areas scale: det=2 means every region doubles in area. When det=0, the transformation collapses a dimension — the grid flattens to a line, and information is permanently lost.

The inverse undoes the verb completely. Apply the transformation, then apply the inverse: you return exactly to where you started. But the inverse only exists when no information was destroyed — when det≠0. Set det=0 with the Collapse preset and watch the inverse disappear. The undo button breaks because there is nothing to undo from.

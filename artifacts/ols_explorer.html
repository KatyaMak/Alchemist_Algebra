The Normal Equations · How the Transpose Makes This Solvable
The system Xβ = y has more equations than unknowns — one per data point, only two unknowns (slope and intercept). No exact solution exists. Multiplying both sides by Xᵀ creates a square solvable system: β = (XᵀX)⁻¹ Xᵀy XᵀX = [ — ] · Xᵀy = [ — ] β = [ β₀ = —, β₁ = — ]
The transpose is not bookkeeping — it is the operation that converts an impossible question into an honest one. XᵀX is always square. When it is invertible, the best-fit coefficients exist uniquely.

No single line passes through all the points. The system is overdetermined — more constraints than degrees of freedom. OLS finds the line that is least wrong: it minimizes the sum of squared vertical distances between each point and the line. Those distances are the residuals.

The matrix transpose is what makes this answerable. The data matrix X has more rows (observations) than columns (parameters). XᵀX is square — same number of rows and columns — and invertible when the data has enough variation. The transpose turns the impossible into the honest best guess. Watch R² approach 1 as the points align, and fall toward 0 as they scatter.
